# Deep Learning for AI (ITAI 2376)

**Houston City College · AI & Robotics Program**

**Instructor:** Prof. Patricia Mcmanus

---

## Course Overview

This course covers the theory and practice of deep learning — from foundational neural network architectures through CNNs, RNNs, Transformers, diffusion models, and reinforcement learning. Assignments explore real-world applications including NLP, computer vision, and generative AI, culminating in a full agentic AI final project.
