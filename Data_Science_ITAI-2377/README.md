# Data Science for AI (ITAI 2377)

**Houston Community College · AI & Robotics Program**

**Instructor:** Prof. Sitaram Ayyagari

---

## Course Overview

This course covers the full data science pipeline as applied to AI and machine learning systems — from raw data ingestion and preprocessing through feature engineering, model training, and deployment. Topics include data wrangling, deep learning data preparation, generative AI preprocessing, neural network data handling, optimization and regularization, and cloud platforms for AI.
